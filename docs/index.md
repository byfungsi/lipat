# Lipat

Create slides from content and layout intent. Edit small pieces by stable identity. Compile once for preview, playback and export.

Lipat has two independent entry paths: semantic authoring and PPTX parsing. Both produce a portable slide scene, and conversion from imported geometry into editable authoring content is explicit.

Start with [creation](./creation), inspect the [architecture](./architecture), or wire an [agent](./agents). See the [support matrix](./support) for the exact implemented scope.
